# Методические указания обучающимся

Данный раздел содержит подробные инструкции для студентов по выполнению практических и лабораторных работ по дисциплине «Аппаратно-программные платформы для систем искусственного интеллекта».

## Структура дисциплины

Дисциплина включает 4 модуля с различными типами практических занятий:

| Модуль | Тип работ | Номера |
|---|---|---|
| Модуль 1. Гетерогенные вычислительные платформы | Практические работы | ПР1, ПР2 |
| Модуль 2. Программно-инфраструктурный слой ML-систем | Практические работы | ПР3, ПР4 |
| Модуль 3. Проектирование вычислительной архитектуры ИИ-систем | Лабораторные работы | ЛР5, ЛР6 |
| Модуль 4. Промышленный ML-инференс | Лабораторные работы | ЛР7, ЛР8 |

## Требования к выполнению работ

### Общие требования

1. Каждая работа выполняется самостоятельно или в группе (до 3 человек).
2. Отчёт оформляется в формате Markdown или PDF.
3. Все результаты должны быть воспроизводимы.
4. Сроки сдачи указаны в учебном плане.

### Структура отчёта

Каждый отчёт должен содержать:

1. **Титульный лист** — номер работы, тема, ФИО студента, группа, дата.
2. **Цель работы** — краткое описание задачи.
3. **Теоретическая часть** — основные понятия и формулы.
4. **Ход выполнения** — пошаговое описание с результатами.
5. **Результаты** — таблицы, графики, скриншоты.
6. **Выводы** — анализ результатов и ответы на контрольные вопросы.

## Практические работы (Модули 1–2)

### ПР1. Профилирование GPU

- **Цель:** Освоение инструментов профилирования GPU (nvidia-smi, DCGM, PyTorch Profiler).
- **Оборудование:** NVIDIA GPU (RTX 3060+), Linux (Ubuntu 22.04), Python 3.11+, PyTorch 2.x.
- **Срок сдачи:** Конец Модуля 1.
- **Максимальный балл:** Входит в КТ 2 (25 баллов).

### ПР2. Бенчмаркинг платформ

- **Цель:** Проведение бенчмаркинга ResNet-50 / BERT-base на различных платформах.
- **Оборудование:** NVIDIA GPU, MLPerf, PyTorch Profiler.
- **Срок сдачи:** Конец Модуля 1.
- **Максимальный балл:** Входит в КТ 2 (25 баллов).

### ПР3. Настройка ML-окружения

- **Цель:** Развёртывание и проверка ML-окружения на Linux.
- **Оборудование:** Linux, NVIDIA драйверы, CUDA, Docker.
- **Срок сдачи:** Конец Модуля 2.
- **Максимальный балл:** Входит в КТ 4 (20 баллов).

### ПР4. Docker для ML

- **Цель:** Создание multi-stage Docker-образа для ML-сервиса.
- **Оборудование:** Docker CE, NVIDIA Container Toolkit, Docker Compose.
- **Срок сдачи:** Конец Модуля 2.
- **Максимальный балл:** Входит в КТ 4 (20 баллов).
