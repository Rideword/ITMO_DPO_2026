# Методические указания преподавателям по использованию ресурсов

Данный раздел содержит инструкции для преподавателей по использованию учебных ресурсов, подготовке к занятиям и организации практических работ по дисциплине «Аппаратно-программные платформы для систем искусственного интеллекта».

## Структура ресурсов

Репозиторий содержит следующие категории ресурсов:

| Папка | Описание |
|---|---|
| `resources/papers/` | Научные статьи и источники литературы |
| `resources/problem-banks/` | Банки задач и кейсов |
| `resources/test-banks/` | Банки тестовых заданий |
| `resources/software/python-libs/` | Python-библиотеки и программные средства |
| `resources/llm-prompts/` | LLM-промпты для генерации заданий |
| `resources/benchmarks/` | Бенчмарки и результаты тестирования |
| `resources/datasets/` | Датасеты для практических работ |

## Подготовка к занятиям

### Модуль 1. Гетерогенные вычислительные платформы

- Подготовить GPU-сервер с NVIDIA CUDA и PyTorch Profiler
- Проверить доступность MLPerf бенчмарков
- Подготовить варианты заданий для практических работ (10 вариантов)

### Модуль 2. Программно-инфраструктурный слой

- Подготовить виртуальную машину или облачный инстанс с Docker и NVIDIA драйверами
- Настроить локальный кластер Kubernetes (kind/minikube)
- Подготовить репозиторий с примером ML-проекта для CI/CD

### Модуль 3. Проектирование вычислительной архитектуры

- Подготовить примеры Roofline-анализа на реальных данных
- Обеспечить доступ к GPU для демонстрации nsys profile
- Подготовить датасеты WikiText-2 и C4 для измерения perplexity

### Модуль 4. Промышленный ML-инференс

- Подготовить демонстрационный model repository для Triton
- Настроить vLLM с OpenAI-совместимым API
- Подготовить примеры дашбордов Evidently AI для drift detection

## Использование LLM-промптов

В папке `resources/llm-prompts/` содержатся шаблоны промптов для генерации заданий:

1. Сравнение GPU-архитектур для задачи инференса
2. Интерпретация Roofline-диаграммы
3. Сравнение методов квантизации LLM
4. Оценка конфигурации инференс-сервера

## Проверка выполнения работ

### Автоматизированная проверка

- Использовать скрипты бенчмаркинга для проверки воспроизводимости результатов
- Проверять наличие обязательных метрик в отчётах
- Сравнивать результаты с эталонными значениями из MLPerf

### Ручная проверка

- Проверить структуру отчёта (титульный лист, введение, выводы)
- Убедиться в наличии графиков и таблиц с подписями
- Проверить ответы на контрольные вопросы на защите

## Технические требования

### Минимальная конфигурация

- ОС: Ubuntu 22.04 LTS
- GPU: NVIDIA RTX 3060 (12 ГБ VRAM)
- RAM: 16 ГБ
- Диск: 100 ГБ (SSD)
- Python: 3.11+
- CUDA: 12.x
- Docker: CE 20.10+

### Рекомендуемая конфигурация

- GPU: NVIDIA RTX 4080 / A100 (24 ГБ VRAM)
- RAM: 32 ГБ
- Диск: 250 ГБ (NVMe SSD)
- Kubernetes кластер (minikube или облачный)
