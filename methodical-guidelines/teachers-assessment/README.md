# Методические указания преподавателям по оцениванию

Данный раздел содержит подробные инструкции для преподавателей по проведению контроля и оцениванию результатов обучения по дисциплине «Аппаратно-программные платформы для систем искусственного интеллекта».

## Система оценки

Дисциплина использует балльную систему оценивания с промежуточными контрольными точками (КТ).

### Контрольные точки (КТ)

| КТ | Тип контроля | Модуль | Макс. баллы |
|---|---|---|---|
| КТ 1 | Тест | Модуль 1 | 25 |
| КТ 2 | Отчёт | ПР 1–2 | 25 |
| КТ 3 | Тест | Модуль 2 | 25 |
| КТ 4 | Отчёт | ПР 3–4 | 20 |
| КТ 5 | Тест | Модуль 3 | 20 |
| КТ 6 | Защита | ЛР 5–6 | 25 |
| КТ 7 | Тест | Модуль 4 | 20 |
| КТ 8 | Защита | ЛР 7–8 | 25 |

**Итого:** 190 баллов

### Перевод в итоговую оценку

| Баллы | Оценка |
|---|---|
| 170–190 | Отлично (5) |
| 140–169 | Хорошо (4) |
| 110–139 | Удовлетворительно (3) |
| < 110 | Касательно (2) |

## Порядок проведения тестов

Тесты проводятся по окончании каждого модуля и включают:

- Закрытые вопросы (выбор одного ответа из 4 вариантов)
- Открытые вопросы (краткий ответ)
- Кейс-задачи (анализ конфигурации)

**Время на тест:** 45 минут
**Количество вопросов:** 15–20
**Порог прохождения:** 70% правильных ответов

## Оценка практических и лабораторных работ

### Критерии оценивания

| Критерий | Вес | Описание |
|---|---|---|
| Полнота выполнения | 40% | Все задания выполнены, результаты получены |
| Качество отчёта | 30% | Структура, оформление, выводы |
| Глубина анализа | 20% | Интерпретация результатов, сравнение |
| Защита | 10% | Ответы на вопросы преподавателя |

### Требования к отчётам

1. Отчёт должен содержать все обязательные разделы.
2. Результаты должны быть воспроизводимы.
3. Графики и таблицы должны иметь подписи.
4. Выводы должны быть обоснованы данными.

## Примечания

- При оценке учитывается индивидуальный вклад каждого студента в группе.
- За каждый день просрочки снимается 10% от максимального балла работы.
- Перезачёт возможен один раз с потерей до 20% баллов.
