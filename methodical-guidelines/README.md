# Методические указания

## Для обучающихся

- Руководство по выполнению каждой практической работы: цель, теоретическая часть, порядок выполнения, требования к отчёту.
- Описание критериев оценивания отчётов и защит (рубрики).
- Шаблоны отчётов по практическим работам (Markdown / LaTeX / MS Word).

## Для преподавателей

- Критерии оценивания по каждому контрольному мероприятию (рубрики с весами).
- Порядок проведения рубежных контрольных (КТ 1–6) и дифференцированного зачёта.
- Инструкция по проверке автоматизированных заданий (скриптов, бенчмарков).

## Ресурсы для составления КИМ

- Банк вопросов (закрытые + открытые) по каждому модулю.
- Датасеты и бенчмарки: MLPerf, Papers with Code SOTA, HuggingFace datasets.
- Шаблоны кейс-заданий (Roofline, матрица выбора платформы, VRAM-расчёт).
- Промпты для генерации вариантов заданий с помощью LLM.
