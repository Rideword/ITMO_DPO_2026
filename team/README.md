## Вклад участников

Участники проекта разработали комплект учебно-методической документации и фонда оценочных средств для дисциплины «Аппаратно-программные платформы для систем искусственного интеллекта». Вклад включает:

- Концепция и методология.
- Разработка контрольно-измерительных материалов.
- Разработка лабораторных работ и проектных заданий.
- Создание критериев и рубрик оценивания.
- Проверка и редактирование материалов.
- Управление проектом.
