# Чек-лист готовности репозитория

## Содержание

- [ ] Название дисциплины и аннотация заполнены.
- [ ] РПД содержит цель, задачи, пререквизиты и проверяемые результаты.
- [ ] Выбраны целевые роли КРМ.
- [ ] Все коды компетенций и индикаторов сверены с КРМ версии 3.0.
- [ ] Модель измерения заполнена для всех модулей и форм аттестации.
- [ ] Каждый обязательный результат обучения подтверждается хотя бы одним КИМ.
- [ ] Каждый КИМ содержит условия, формат сдачи, критерии и шкалу.
- [ ] Баллы в рубриках согласованы с итоговой таблицей.
- [ ] Описаны правила допустимого использования LLM и внешних ресурсов.
- [ ] Добавлены методические указания обучающимся и преподавателям.
- [ ] Ресурсы имеют аннотации и рабочие ссылки.
- [ ] Указаны авторы, роли и вклад участников.
- [ ] Выбрана и согласована лицензия.

## Техническая проверка

- [ ] Нет незаполненных маркеров `[ЗАПОЛНИТЬ]` в публикуемой версии.
- [ ] Относительные Markdown-ссылки работают.
- [ ] Нет временных файлов офисных приложений.
- [ ] Крупные файлы не превышают ограничения GitHub или вынесены во внешнее хранилище.

## Проверка интеграции международных стандартов

- [ ] В репозитории существует файл `resources/ai-standards/README.md` с картой стандартов.
- [ ] Файл `resources/README.md` содержит ссылку на `ai-standards.md`.
- [ ] Корневой `README.md` содержит раздел о международной нормативно-методической базе.
- [ ] `docs/rpd.md` содержит раздел о международных стандартах и связи с компетенциями.
- [ ] README модулей M1–M4 содержат блок «Нормативно-методическая связь» со ссылкой на `../resources/ai-standards/README.md`.
- [ ] `Project/README.md` содержит раздел «Стандарты и артефакты ответственного жизненного цикла».
- [ ] `Project/case-example.md` содержит примеры заполнения риск-реестра, SLO и LLM safety checklist.
- [ ] `methodical-guidelines/students/README.md` содержит инструкцию по использованию стандартов.
- [ ] `methodical-guidelines/teachers-assessment/README.md` содержит критерии проверки артефактов стандартов.

## Проверка проектных артефактов

- [ ] В проекте есть паспорт модели и сервиса (модель, версия, конфигурация, ограничения).
- [ ] В проекте есть реестр рисков (риск, вероятность, влияние, мера контроля).
- [ ] В проекте есть паспорт данных (источник, лицензия, ограничения, качество).
- [ ] В проекте есть матрица качества и SLO (P95 latency, throughput, error rate, VRAM).
- [ ] В проекте есть LLM/GenAI safety checklist (hallucination, prompt injection, leakage, аудит).
- [ ] Все измерения (latency, throughput, VRAM) получены экспериментально, а не подменены ответами LLM.
- [ ] Указаны воспроизводимые команды запуска и версии ПО.
- [ ] Студент готов к устной защите ключевых архитектурных решений и результатов замеров.
