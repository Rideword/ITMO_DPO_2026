## Требования к добавлению

Для каждого банка укажите темы, количество заданий, уровни сложности, правила выборки, ключи и порядок обновления.

### Общие параметры тестов

- **Уровень сложности:** средний.
- **Оценка:** вопрос с выбором ответа — 1 балл; вопрос с открытым ответом (цифра/аббревиатура/выражение до 3 слов) — 2 балла.
- **Максимум:** 20 баллов за каждый тест.
- **Структура:** 12 вопросов с выбором ответа + 4 открытых вопроса.

### Правила выборки

- Каждый тест покрывает все темы соответствующего модуля.
- Вопросы привязаны к конкретным лекциям (указано в заголовке вопроса).
- Ключи ответов включены в каждый файл теста.

### Порядок обновления

- При изменении содержания лекций обновлять соответствующие вопросы.
- Добавлять новые вопросы при расширении тем.
- Актуализировать дату проверки в таблице выше.
