## Промпты для анализа архитектуры GPU

### Промпт 1: Сравнение GPU-архитектур для задачи инференса

**Модель/сервис:** GPT-4 / LLaMA-3 8B  
**Назначение:** Сравнение GPU-платформ для выбора оптимальной конфигурации под задачу инференса.  
**Входные данные:** Параметры задачи (batch size, модель, формат весов, целевая latency).  
**Ожидаемый формат результата:** Таблица сравнения (GPU, VRAM, FLOPS, Bandwidth, TDP, оценка стоимости).  
**Ограничения:** Ответ не должен превышать 500 слов.  
**Способ верификации:** Сверка с паспортными данными GPU (NVIDIA NGC, AMD ROCm).

```
Ты — инженер по аппаратным платформам для ИИ. Задание: сравнить следующие GPU-платформы для задачи инференса LLaMA-3 8B в формате FP16:

Платформы: NVIDIA A100 80GB, NVIDIA RTX 4090 24GB, NVIDIA H100 80GB SXM5, AMD MI300X.

Параметры задачи:
- Модель: LLaMA-3 8B (FP16)
- Batch size: 1, 32, 128
- Целевая latency (batch=1): < 50 мс на токен
- Целевой throughput: > 50 токенов/сек

Предоставь таблицу сравнения с параметрами: VRAM, Peak FLOPS (FP16), Peak Bandwidth, TDP, примерная стоимость.
Сделай вывод о лучшей платформе для каждого сценария (batch=1, batch=32, batch=128).
```

## Промпты для анализа Roofline-модели

### Промпт 2: Интерпретация Roofline-диаграммы

**Модель/сервис:** GPT-4 / LLaMA-3 8B  
**Назначение:** Интерпретация Roofline-диаграммы и рекомендации по оптимизации.  
**Входные данные:** Данные о платформе (Peak FLOPS, Bandwidth) и операторах (FLOPs, Bytes).  
**Ожидаемый формат результата:** Анализ (классификация операторов, bottleneck, рекомендации).  
**Ограничения:** Ответ должен содержать формулы расчёта.  
**Способ верификации:** Сверка расчётов Ridge Point и AI с эталонными значениями.

```
Ты — инженер по оптимизации производительности ИИ-систем. Задание: проанализировать Roofline-диаграмму для платформы NVIDIA A100.

Параметры платформы:
- Peak FLOPS (FP16): 312 TFLOP/s
- Peak Bandwidth (HBM2e): 2000 GB/s

Операторы нейросети:
- Fully-Connected (768×4096): FLOPs = 6.3G, Bytes = 17.4M → AI = 362
- Conv2D (64×64×3×32): FLOPs = 3.7M, Bytes = 1.2M → AI = 3.1
- Attention (seq=512, d=768): FLOPs = 1.5G, Bytes = 3.1M → AI = 484

1. Рассчитай Ridge Point для A100.
2. Классифицируй каждый оператор (memory-bound или compute-bound).
3. Дай рекомендации по оптимизации для каждого оператора.
```

## Промпты для сравнения методов квантизации

### Промпт 3: Сравнение методов квантизации LLM

**Модель/сервис:** GPT-4 / LLaMA-3 8B  
**Назначение:** Сравнение методов квантизации для выбора оптимального метода.  
**Входные данные:** Параметры модели и целевого железа.  
**Ожидаемый формат результата:** Таблица сравнения методов с оценкой качества, VRAM, скорости.  
**Ограничения:** Ответ должен содержать ссылки на источники.  
**Способ верификации:** Сверка с результатами бенчмаркинга (MLPerf, Hugging Face).

```
Ты — ML-инженер, специализирующийся на оптимизации LLM. Задание: сравнить методы квантизации для модели LLaMA-3 8B.

Методы: GPTQ (4-bit), AWQ (4-bit), BitsAndBytes (NF4), GGUF (Q4_K_M).

Параметры:
- Целевая платформа: NVIDIA RTX 4090 (24 GB VRAM)
- Целевой формат: INT4
- Метрика качества: Perplexity на WikiText-2

Предоставь таблицу сравнения с параметрами:
- Объём модели (VRAM)
- Скорость инференса (токенов/сек)
- Perplexity (PPL) на WikiText-2
- Преимущества и недостатки

Сделай вывод о лучшем методе для каждой конфигурации (Edge, Server, Cloud).
```

## Промпты для оценки конфигурации инференса

### Промпт 4: Оценка конфигурации инференс-сервера

**Модель/сервис:** GPT-4 / LLaMA-3 8B  
**Назначение:** Оценка конфигурации инференс-сервера (Triton, vLLM) для выбора оптимального решения.  
**Входные данные:** Параметры задачи (модель, batch size, целевая latency/throughput).  
**Ожидаемый формат результата:** Сравнительный анализ конфигураций с рекомендациями.  
**Ограничения:** Ответ должен содержать конкретные цифры.  
**Способ верификации:** Сверка с результатами нагрузочного тестирования.

```
Ты — MLOps-инженер. Задание: оценить конфигурации инференс-сервера для модели LLaMA-3 8B.

Конфигурации:
1. vLLM с PagedAttention (GPU: A100 40GB)
2. Triton Inference Server + ONNX Runtime (GPU: A100 40GB)
3. TorchServe (GPU: RTX 4090 24GB)

Параметры задачи:
- Модель: LLaMA-3 8B (FP16)
- Целевая latency (TTFT): < 200 мс
- Целевой throughput: > 50 токенов/сек
- Batch size: 1–32

Предоставь сравнительный анализ с оценкой:
- Ожидаемая latency и throughput
- Утилизация GPU
- Требования к VRAM
- Преимущества и недостатки

Сделай вывод о лучшей конфигурации для каждого сценария.
```

## Общие рекомендации по использованию промптов

1. Адаптируйте входные данные под конкретную задачу и платформу.
2. Проверяйте результаты на соответствие техническим характеристикам оборудования.
3. Используйте промпты как основу для анализа, а не как окончательный ответ.
4. Обновляйте промпты при изменении версий моделей и платформ.
