## Требования к добавлению

При добавлении нового датасета в таблицу необходимо указать:

- **Источник** — официальный сайт, репозиторий или организация-владелец данных.
- **Лицензию** — условия использования (открытая лицензия, ограничения на коммерческое использование, требование согласия и т. п.).
- **Состав признаков** — перечень полей/колонок, их типы и краткое описание.
- **Целевую переменную** — что предсказывается или классифицируется (если применимо).
- **Объём** — количество записей/изображений/токенов, объём в ГБ.
- **Ограничения** — известные ограничения на использование (например, только для образовательных целей, необходимость анонимизации).
- **Возможные смещения** — дисбаланс классов, смещения по времени/региону/языку, которые могут повлиять на выводы студентов.
- **Рекомендуемое разбиение** — train/validation/test split, если он предустановлен или рекомендуется для практических работ.
