## Требования к добавлению

Для каждой задачи укажите проверяемый результат, сложность, входные данные, эталон или подход к проверке и варианты параметризации.

### Пример описания задачи

```markdown
### Задача: Расчёт VRAM для обучения LLaMA-3 8B

**Сложность:** Средняя
**Входные данные:**
- Количество параметров: 8B
- Формат весов: FP16
- Оптимизатор: AdamW
- Batch size: 32
- Sequence length: 2048

**Проверяемый результат:**
- Объём памяти для весов (16 ГБ)
- Объём памяти для градиентов (16 ГБ)
- Объём памяти для состояний оптимизатора (64 ГБ)
- Общий объём VRAM (без активаций): 96 ГБ

**Подход к проверке:**
Сравнение расчётов с эталонной формулой:
Total VRAM = Weights + Gradients + Optimizer States + Activations + Overheads

**Варианты параметризации:**
- Изменение формата весов (FP32, INT8, INT4)
- Смена оптимизатора (SGD, Adam, AdamW)
- Добавление Gradient Checkpointing
```

### Общие требования

1. Каждая задача должна иметь чётко определённый проверяемый результат.
2. Указывать уровень сложности (Легкая, Средняя, Сложная).
3. Предоставлять входные данные в структурированном виде.
4. Описывать подход к проверке (формула, эталонное значение, диапазон).
5. Предлагать варианты параметризации для масштабирования задачи.
6. Связывать задачу с соответствующим модулем и компетенцией.
