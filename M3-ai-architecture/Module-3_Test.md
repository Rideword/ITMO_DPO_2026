# Тест по Модулю 3. Проектирование вычислительной архитектуры ИИ-систем

**Уровень сложности:** средний.
**Оценка:** вопрос с выбором ответа — 1 балл; вопрос с открытым ответом (цифра/аббревиатура/выражение до 3 слов) — 2 балла.
**Максимум:** 20 баллов.

---

## Вопросы с выбором ответа (12 вопросов × 1 балл)

### Вопрос 1 (Лекция 3.1)

**Из каких вершин состоит «Треугольник ограничений ИИ-систем»?**

- A) Стоимость, время, качество
- B) Точность (Accuracy), задержка (Latency/Throughput), энергия и бюджет (Power & Cost)
- C) Память, процессор, сеть
- D) Данные, модель, инфраструктура

**Правильный ответ:** B) Точность (Accuracy), задержка (Latency/Throughput), энергия и бюджет (Power & Cost)

---

### Вопрос 2 (Лекция 3.1)

**Сколько уровней абстракции традиционно выделяют в аппаратно-программном кодизайне?**

- A) 2 (Software, Hardware)
- B) 3 (Algorithmic, System, Circuit)
- C) 4 (Business, Algorithmic, System, Circuit)
- D) 5

**Правильный ответ:** B) 3 (Algorithmic, System, Circuit)

---

### Вопрос 3 (Лекция 3.1)

**Какой вес присваивается критерию в Weighted Decision Matrix (WDM), если он представляет жёсткое ограничение (Hard Constraint)?**

- A) 0.1–0.2
- B) 0.3–0.5
- C) 0.9–1.0
- D) Вес не назначается

**Правильный ответ:** C) 0.9–1.0

---

### Вопрос 4 (Лекция 3.2)

**Какая формула корректно описывает объём памяти, необходимый для обучения модели?**

- A) Memory = Weights + Gradients
- B) Memory = Weights + Gradients + Optimizer States + Activations + Overheads
- C) Memory = Weights × Batch size
- D) Memory = FLOPs / Bandwidth

**Правильный ответ:** B) Memory = Weights + Gradients + Optimizer States + Activations + Overheads

---

### Вопрос 5 (Лекция 3.2)

**Как вычисляется Ridge Point на Roofline-диаграмме?**

- A) Peak Bandwidth / Peak FLOP/s
- B) Peak FLOP/s / Peak Bandwidth
- C) Peak FLOP/s × Peak Bandwidth
- D) (Peak FLOP/s + Peak Bandwidth) / 2

**Правильный ответ:** B) Peak FLOP/s / Peak Bandwidth

---

### Вопрос 6 (Лекция 3.2)

**Оператор классифицируется как memory-bound, если:**

- A) AI > AI_ridge
- B) AI < AI_ridge
- C) AI = AI_ridge
- D) AI не влияет на классификацию

**Правильный ответ:** B) AI < AI_ridge

---

### Вопрос 7 (Лекция 3.3)

**Какой тип параллелизма рекомендуется применять внутри одного узла с NVLink?**

- A) Pipeline Parallelism (PP)
- B) Tensor Parallelism (TP)
- C) Только Data Parallelism (DP)
- D) Federated Learning

**Правильный ответ:** B) Tensor Parallelism (TP)

---

### Вопрос 8 (Лекция 3.3)

**Что шардирует ZeRO-3 (и соответствующий FSDP)?**

- A) Только состояния оптимизатора
- B) Состояния оптимизатора и градиенты
- C) Веса, градиенты и состояния оптимизатора
- D) Только активации

**Правильный ответ:** C) Веса, градиенты и состояния оптимизатора

### Вопрос 9 (Лекция 3.3)

**Для чего предназначен оптимизатор LAMB?**

- A) Уменьшения размера модели
- B) Стабильного обучения с очень большими батчами
- C) Квантизации весов
- D) Ускорения инференса на Edge-устройствах

**Правильный ответ:** B) Стабильного обучения с очень большими батчами

### Вопрос 10 (Лекция 3.4)

**Чему равен Zero Point (Z) при симметричной квантизации?**

- A) Максимальному значению тензора
- B) Нулю
- C) Медиане распределения
- D) Среднему значению активаций

### Вопрос 11 (Лекция 3.4)

**Какой метод специально разработан для решения проблемы выбросов (outliers) в активациях LLM при INT8-квантизации?**

### Вопрос 14 (Лекция 3.2)
