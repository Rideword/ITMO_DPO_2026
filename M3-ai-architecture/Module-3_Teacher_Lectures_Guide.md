Методические указания преподавателю по лекционному материалу (коротко). Модуль 3.

**Лекция 3.1. Методология выбора платформы**
Перед лекцией подготовить:
пример реального SLA-документа или его фрагмент;
кейс с числовыми требованиями (RPS, latency p95, бюджет) для разбора на занятии.
Демонстрация должна включать:
разбор постановки задачи по шагам (формализация SLA → профиль нагрузки → выбор класса платформы);
сравнение 2-3 альтернативных вариантов платформ для одного и того же кейса.

**Лекция 3.2. Расчёт ресурсов: Roofline, Arithmetic Intensity, VRAM-бюджет, Chinchilla Laws**
Перед лекцией подготовить:
калькулятор/таблицу (Excel или Python-скрипт) для расчёта VRAM-бюджета обучения и инференса;
графическую иллюстрацию Chinchilla Scaling Laws.
Демонстрация должна включать:
пошаговый расчёт VRAM для модели заданного размера (веса, градиенты, оптимизатор, KV-cache);
построение Roofline-диаграммы «на лету» для 1-2 операций.

**Лекция 3.3. Распределённое обучение: Data/Tensor/Pipeline Parallelism, ZeRO, NCCL**
Перед лекцией подготовить:
схемы-иллюстрации трёх видов параллелизма;
при наличии мультиGPU-сервера – демонстрацию запуска NCCL All-Reduce (nccl-tests) или конфигурации DeepSpeed ZeRO.
Демонстрация должна включать:
сравнение топологий interconnect (NVLink/InfiniBand/PCIe) по пропускной способности;
пример конфигурационного файла DeepSpeed с указанием stage ZeRO.
При отсутствии мультиGPU-кластера можно продемонстрировать:
теоретический разбор конфигураций ZeRO Stage 1/2/3 по документации DeepSpeed.

**Лекция 3.4. Квантизация и оптимизация: INT8/INT4/FP8, AWQ, GPTQ, TensorRT**
Перед лекцией подготовить:
две версии одной модели — исходную (FP16) и квантизованную (GPTQ или AWQ, INT4) — для сравнения размера файлов и (при наличии GPU) скорости инференса;
пример конфигурации TensorRT (или engine-файл) для демонстрации компиляции.
Демонстрация должна включать:
сравнение размера модели на диске и в VRAM до/после квантизации;
запуск инференса квантизованной модели и измерение TTFT/TPOT (если доступен GPU).
При отсутствии GPU продемонстрировать:
сравнение показателей качества/скорости/памяти по опубликованным бенчмаркам (карточки моделей на Hugging Face).
