Методические указания преподавателю по лекциям модуля 3

Модуль 3. Проектирование вычислительной архитектуры ИИ-систем.

Общая цель модуля: сформировать у студентов инженерный подход к выбору аппаратно-программной платформы под задачу ИИ, умение численно оценивать ресурсы (память, FLOPS), проектировать распределённое обучение и применять методы квантизации.

Рекомендации по проведению Лекции 3.1 (HW/SW Co-Design):

Начать с наглядного примера противоречия (например, автопилот vs облачный чат-бот), чтобы студенты почувствовали суть треугольника ограничений до введения формализма WDM.

Обязательно разобрать пример турникета метро (Hard Constraints) на доске совместно со студентами — этот пример закладывает базу для практики ПР5.

При разборе матрицы WDM желательно провести мини-упражнение в аудитории: попросить студентов проставить веса для 2–3 критериев самостоятельно и сравнить результаты.

Рекомендации по проведению Лекции 3.2 (Compute Estimation & Profiling):

Формулы расчёта VRAM и FLOPs следует разбирать на конкретных числах (Llama-2 7B), не ограничиваясь общими формулами — это критично для успешного выполнения ПР5 и ПР6.

Подчеркнуть разницу между Roofline-анализом «на бумаге» и реальным профайлингом (Nsight) — обе части необходимы инженеру.

Если есть доступ к GPU в аудитории, показать живую демонстрацию nsys profile на простом скрипте.

Рекомендации по проведению Лекции 3.3 (Distributed Training):

Использовать визуальные схемы (DP/TP/PP) — рекомендуется подготовить слайды с анимацией передачи данных между GPU, так как это сложная для восприятия тема.

Обязательно связать выбор стратегии параллелизма с топологией сети (NVLink vs InfiniBand) — это ключевой инженерный вывод модуля.

Рекомендации по проведению Лекции 3.4 (Quantization):

Показать наглядно на числовом примере (одно число FP32 → INT8) процесс квантизации и деквантизации перед переходом к сложным методам (GPTQ, AWQ).

Подчеркнуть, что perplexity — не абсолютная метрика, а сравнительная (ΔPPL от базовой модели), и её интерпретация зависит от калибровочного датасета.

Общие методические рекомендации:

Между лекциями 3.2 и 3.4 рекомендуется дать студентам самостоятельное мини-задание (оценить VRAM для своей модели) — это подготовит их к ПР6.

Использовать вопросы к лекциям (файл «Вопросы по лекциям. Модуль 3») как основу для входного контроля перед практическими занятиями.

Материалы модуля тесно связаны между собой: без понимания Roofline (Лекция 3.2) невозможно грамотно спроектировать распределённое обучение (Лекция 3.3) или оценить эффект квантизации (Лекция 3.4).
