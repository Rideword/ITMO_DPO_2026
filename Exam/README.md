# Дифференцированный зачёт

## Описание

Дифференцированный зачёт является формой промежуточной аттестации по дисциплине «Аппаратно-программные платформы для систем искусственного интеллекта».

## Формат проведения

Дифференцированный зачёт проводится на основе текущего рейтинга студента с возможностью улучшения результата посредством устной защиты.

### Вариант 1: Оценка по текущему рейтингу

Оценка выставляется на основе текущего рейтинга студента в соответствии с критериями оценивания.

**Шкала итоговой оценки:**

| Баллы | Оценка |
|---|---|
| 0–55 | Неудовлетворительно |
| 56–70 | Удовлетворительно |
| 71–85 | Хорошо |
| 86–100 | Отлично |

### Вариант 2: Улучшение результата через устную защиту

В случае если студент не согласен с оценкой по текущему рейтингу, он может улучшить результат, ответив на ряд вопросов по всем модулям дисциплины.

**Формат устной защиты:**

- Студенту задается ряд вопросов из банка вопросов по всем 4 модулям дисциплины.
- Студент отвечает на вопросы устно перед комиссией преподавателей.
- Вопросы охватывают все темы: гетерогенные архитектуры, инфраструктуру ML-систем, проектирование вычислительной архитектуры и промышленный ML-инференс.

**Расчет итоговой оценки:**

| Компонент | Вес |
|---|---|
| Текущий рейтинг | 60% |
| Оценка на зачёте | 40% |

**Формула расчета:**

```
Итоговая оценка = (Текущий рейтинг × 0.6) + (Оценка на зачёте × 0.4)
```

## Банк вопросов

Вопросы для устной защиты формируются из вопросов к лекциям всех модулей дисциплины:

- [Вопросы к лекциям Модуля 1](../M1-heterogeneous-platforms/Module-1_Lectures_Questions.md) — Гетерогенные вычислительные платформы
- [Вопросы к лекциям Модуля 2](../M2-ml-infrastructure/Module-2_Lectures_Questions.md) — Программно-инфраструктурный слой
- [Вопросы к лекциям Модуля 3](../M3-ai-architecture/Module-3_Lectures_Questions.md) — Проектирование вычислительной архитектуры
- [Вопросы к лекциям Модуля 4](../M4-ml-inference/Module-4_Lectures_Questions.md) — Промышленный ML-инференс

## Порядок проведения

1. Студент получает уведомление о дате и времени зачёта.
2. На зачёте преподаватель объявляет текущий рейтинг студента.
3. Студент выбирает вариант:
   - Принять оценку по текущему рейтингу.
   - Пройти устную защиту для улучшения результата.
4. При выборе устной защиты студенту задаются вопросы из банка вопросов.
5. Итоговая оценка рассчитывается по формуле: 60% текущего рейтинга + 40% оценки на зачёте.

## Критерии оценивания устной защиты

Оценка на зачёте выставляется по следующим критериям:

| Критерий | Описание | Макс. баллы |
|---|---|---|
| Полнота ответа | Ответ охватывает все аспекты вопроса | 40 |
| Глубина понимания | Демонстрация понимания концепций и принципов | 30 |
| Практическое применение | Умение связать теорию с практическими задачами | 20 |
| Качество изложения | Ясность, структурированность, терминология | 10 |
| **Итого** | | **100** |
