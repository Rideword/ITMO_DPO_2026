# Проектная работа

Проектная работа — интегральный КИМ, позволяющий проверить несколько компетенций и индикаторов в условиях комплексной практической задачи.

---

## Пример кейса индустриального партнёра

Подробное описание примера кейса см. в файле [`case-example.md`](case-example.md).

### Краткое описание

Разрабатывается веб-сервис обработки запросов на естественном языке для BI-системы компании-партнёра. Система позволяет пользователям формулировать запросы на русском языке, которые с помощью LLM классифицируются и преобразуются в JSON-параметры для вызова веб-сервиса отчётов.

### Цель проекта

Создать веб-сервис для классификации и обработки запросов пользователей с преобразованием их в JSON для вызовов типовых отчётов с фактическими параметрами, извлекаемыми из запроса с помощью LLM.

### Ожидаемый результат

- Веб-сервис для обработки запросов на естественном языке.
- Библиотека промптов для LLM, позволяющая извлекать параметры запросов данных о продажах.

### Технические требования

- **RPS:** ≥ 2
- **Latency p95:** < 500 мс
- **Контекст:** 4K токенов
- **Модель:** на Hugging Face
- **GPU:** NVIDIA RTX 3060 (12 ГБ VRAM)
- **Срок:** 3 недели

### Описание API

API предоставляет список сделок с возможностью фильтрации и сортировки по следующим полям: `ID`, `TITLE`, `TYPE_ID`, `CATEGORY_ID`, `STAGE_ID`, `PRICE`, `MANAGER_ID`, `DATE_CREATE`.

Подробные форматы `FILTER` и `ORDER`, а также примеры запросов и ответов описаны в файле [`case-example.md`](case-example.md).
