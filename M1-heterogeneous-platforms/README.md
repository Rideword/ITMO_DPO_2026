# Модуль 1. Гетерогенные вычислительные платформы для систем ИИ

## Описание модуля

Модуль посвящен изучению гетерогенных вычислительных архитектур для систем искусственного интеллекта: CPU, GPU, TPU, FPGA, NPU, гибридных и кластерных конфигураций. Рассматриваются методы выбора платформы по критериям VRAM, bandwidth, TDP, latency, throughput и TCO.

## Содержание тем

### 1.1 Обзор гетерогенных архитектур

Понятие гетерогенной вычислительной системы. Назначение CPU, GPU, TPU, FPGA и NPU в задачах ИИ. Классификация архитектур по Флинну; принципы SIMD и SIMT. Критерии сопоставления производительности, памяти, энергопотребления и программируемости.

### 1.2 Архитектура GPU

Микроархитектура GPU: потоковые мультипроцессоры (SM), warps, иерархия памяти, Tensor Cores. Роль HBM/GDDR, PCIe и NVLink. Связь архитектурных параметров с производительностью обучения и инференса нейросетей.

### 1.3 FPGA/NPU для ИИ

Особенности программируемой логики и специализированных ускорителей. Ресурсы FPGA: LUT, DSP, BRAM; конвейеризация и потоковая обработка. Архитектуры NPU и сценарии их применения в edge-устройствах и системах реального времени.

### 1.4 Выбор платформы для ИИ-задач

Методика выбора платформы для CV, LLM, табличного МО и потокового инференса. Сопоставление VRAM, пропускной способности памяти, TDP, latency, throughput, стоимости владения и требований к масштабированию.

## Практические работы

### ПР1. Профилирование GPU

**Цель:** Настройка среды измерений. Сбор метрик GPU средствами nvidia-smi и DCGM; профилирование PyTorch-модели. Анализ загрузки SM, памяти, CPU и выявление ограничивающих факторов производительности.

### ПР2. Бенчмаркинг платформ

**Цель:** Проведение воспроизводимого бенчмарка ResNet-50 или BERT-base. Измерение latency, throughput, потребления памяти и утилизации GPU; сравнение конфигураций batch size и precision; подготовка выводов.
