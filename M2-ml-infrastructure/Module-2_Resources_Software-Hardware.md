  
Практические занятия по модулю 2

Требования по оборудованию и ПО для выполнения заданий.

Студентам должны быть доступны:

Docker Desktop или Docker Engine на Linux для сборки и запуска контейнеров.

Docker Compose для поднятия связки «ML‑сервис \+ БД/хранилище \+ мониторинг» одной командой.  
Python 3.10+ и базовый ML‑стек: NumPy, pandas, scikit-learn, FastAPI или Flask для inference‑сервиса.

Git и GitHub/GitLab для хранения кода и триггера пайплайнов.

GitHub Actions или GitLab CI для CI/CD: тесты, сборка образа, прогон валидации и деплой.

MLflow для трекинга экспериментов и регистрации модели.

Great Expectations или Pandera для проверки качества и схемы данных перед обучением.

Prometheus \+ Grafana для метрик сервиса и визуализации.  
datafinder

Evidently для мониторинга дрейфа данных и качества ML‑модели.

Для учебной версии достаточно обычного ноутбука или ПК с 16 ГБ RAM и 20–30 ГБ   
свободного диска; этого хватит для контейнеров, простых моделей и мониторинга.

Если необходимо показать GPU‑обучение или ускоренный инференс, нужен Linux‑хост с NVIDIA GPU и NVIDIA Container Toolkit, чтобы контейнеры могли использовать видеокарту.  
   
Для более комфортной групповой работы удобно иметь один выделенный сервер или VM, где крутится registry, CI‑runner и мониторинг.

Рекомендованный набор для выполнения практических занятий

| Компонент | Рекомендация | Зачем |
| :---- | :---- | :---- |
| Контейнеризация | Docker, Docker Compose | Упаковка и запуск ML‑сервиса  |
| CI/CD | GitHub Actions или GitLab CI | Автоматизация тестов, сборки и деплоя  |
| Трекинг моделей | MLflow | Версионирование экспериментов и моделей |
| Валидация данных | Great Expectations или Pandera | Контроль входных данных перед обучением  |
| Метрики | Prometheus, Grafana | Сбор и визуализация технических метрик  |
| ML‑мониторинг | Evidently | Дрейф данных, качество модели, отчёты  |
| Логи | Loki или ELK | Анализ ошибок и трассировка инцидентов  |
