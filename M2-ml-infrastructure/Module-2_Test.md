# Тест по Модулю 2. Программно-инфраструктурный слой: Linux / Docker / K8s / CI-CD / мониторинг

**Уровень сложности:** средний.  
**Оценка:** вопрос с выбором ответа — 1 балл; вопрос с открытым ответом (цифра/аббревиатура/выражение до 3 слов) — 2 балла.  
**Максимум:** 20 баллов.

---

## Вопросы с выбором ответа (12 вопросов × 1 балл)

### Вопрос 1 (Лекция 2.1)

**Какой инструмент используется для установки ограничений и учёта ресурсов процессов в Linux (например, для GPU-сервера)?**

- A) cgroups
- B) systemd-journald
- C) apt
- D) tmux

**Правильный ответ:** A) cgroups

---

### Вопрос 2 (Лекция 2.1)

**Что необходимо сделать перед установкой проприетарного драйвера NVIDIA на Ubuntu, согласно рассмотренной последовательности?**

- A) Установить Docker
- B) Внести nouveau в blacklist и установить kernel headers
- C) Настроить Kubernetes
- D) Установить MLflow

**Правильный ответ:** B) Внести nouveau в blacklist и установить kernel headers

---

### Вопрос 3 (Лекция 2.1)

**Какой командой инженер проверяет работоспособность драйвера GPU и текущую загрузку устройства?**

- A) nvidia-smi
- B) htop
- C) pip freeze
- D) docker ps

**Правильный ответ:** A) nvidia-smi

---

### Вопрос 4 (Лекция 2.2)

**Какая техника сборки Docker-образа позволяет отделить этап компиляции/сборки от финального образа, уменьшая его размер?**

- A) Bind mount
- B) Multistage build
- C) Docker network host
- D) Volume mapping

**Правильный ответ:** B) Multistage build

---

### Вопрос 5 (Лекция 2.2)

**Какой флаг команды docker run обеспечивает доступ контейнера к GPU через NVIDIA Container Toolkit?**

- A) --network
- B) --gpus
- C) --volume
- D) --env

**Правильный ответ:** B) --gpus

---

### Вопрос 6 (Лекция 2.2)

**Какой инструмент используется для сканирования уязвимостей Docker-образов, упомянутый в лекции?**

- A) Trivy
- B) MLflow
- C) DVC
- D) kubelet

**Правильный ответ:** A) Trivy

---

### Вопрос 7 (Лекция 2.3)

**Какой компонент control plane Kubernetes отвечает за хранение состояния кластера?**

- A) kubelet
- B) etcd
- C) kube-proxy
- D) Ingress Controller

**Правильный ответ:** B) etcd

---

### Вопрос 8 (Лекция 2.3)

**Какой механизм Kubernetes позволяет автоматически увеличивать количество Pod при росте нагрузки на инференс-сервис?**

- A) HPA (Horizontal Pod Autoscaler)
- B) StatefulSet
- C) ConfigMap
- D) NetworkPolicy

**Правильный ответ:** A) HPA (Horizontal Pod Autoscaler)

---

### Вопрос 9 (Лекция 2.3)

**Что используется для изоляции GPU-узлов кластера так, чтобы на них планировались только соответствующие поды?**

- A) ConfigMap и Secret
- B) Node taints и tolerations
- C) Ingress и NetworkPolicy
- D) PV и PVC

**Правильный ответ:** B) Node taints и tolerations

---

### Вопрос 10 (Лекция 2.4)

**Какие из перечисленных являются «золотыми сигналами» мониторинга согласно лекции?**

- A) Задержка, трафик, ошибки, насыщенность
- B) CPU, RAM, диск, сеть
- C) Версия драйвера, версия CUDA, версия ядра
- D) Git-коммиты, ветки, тэги

**Правильный ответ:** A) Задержка, трафик, ошибки, насыщенность

---

### Вопрос 11 (Лекция 2.4)

**Какая система собирает метрики GPU NVIDIA и экспортирует их в Prometheus?**

- A) DCGM-exporter
- B) Fluent Bit
- C) Jaeger
- D) Argo CD

**Правильный ответ:** A) DCGM-exporter

---

### Вопрос 12 (Лекция 2.4)

**Какой стандарт объединяет сбор метрик, логов и трассировок для наблюдаемости распределённых систем?**

- A) OpenTelemetry
- B) Helm
- C) RBAC
