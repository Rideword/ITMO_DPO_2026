**ПР7. Бенчмаркинг и нагрузочное тестирование систем инференса LLM (Triton/vLLM)**

**Форма оценки:** зачёт/незачёт.

**Критерии для получения «Зачёта» (студент обязан выполнить все пункты):**

* Успешно развёрнут Triton Inference Server и выполнен запуск perf_analyzer с получением метрик throughput/latency для минимум двух уровней параллелизма.

* Успешно развёрнут vLLM-сервер и выполнено нагрузочное тестирование через Locust (headless или веб-режим) с получением RPS, latency, TTFT.

* Выполнен хотя бы один эксперимент с оптимизацией (dynamic batching в Triton или изменение параметров запуска vLLM) с сопоставлением результатов «до/после».

* Сдан отчёт, соответствующий требованиям к структуре и содержащий все обязательные элементы (таблицы, графики, анализ, выводы).

**Основания для «Незачёта»:**

* Отсутствие рабочего окружения и невозможность продемонстрировать выполнение ключевых шагов.

* Отсутствие отчёта или его формальное несоответствие требованиям.

* Плагиат (копирование чужих отчётов/скриптов без указания источника).

**Требования к отчету:**

* Структура: титульный лист (ФИО, группа, дата, тема), цель работы, ход выполнения (запуск Triton/perf_analyzer, запуск vLLM/Locust, эксперимент с оптимизацией), результаты, анализ результатов, выводы, приложения.

* Обязательные элементы: таблица результатов perf_analyzer для разных уровней параллелизма; график throughput vs concurrency; таблица/график результатов Locust; сравнительная таблица Triton vs vLLM; выводы о влиянии оптимизации.

* Срок сдачи: не позднее 7 календарных дней после занятия, формат PDF.
