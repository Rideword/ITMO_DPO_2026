Методические указания преподавателю по лекционному материалу (коротко). Модуль 4.

**Лекция 4.1. Серверный инференс: Triton, TorchServe, vLLM, ONNX/TRT/GGUF, batching**
Перед лекцией подготовить:
демонстрационный model repository для Triton (минимальный пример «simple»);
сравнительную таблицу форматов (ONNX/TRT/GGUF) по размеру файла и целевому железу.
Демонстрация должна включать:
запуск Triton-контейнера и проверку готовности сервера (`curl localhost:8000/v2/health/ready`);
краткий обзор запуска vLLM с OpenAI-совместимым API.

**Лекция 4.2. Оптимизация инференса: PagedAttention, Flash Attention, Speculative Decoding, KV-cache**
Перед лекцией подготовить:
графическую иллюстрацию Tiling и Online Softmax (Flash Attention);
графическую иллюстрацию Block Table и физических блоков памяти (PagedAttention).
Демонстрация должна включать:
сравнение TTFT/TPOT на реальном запуске vLLM (если доступен GPU) при разных значениях batch size;
разбор реального лог-файла/дашборда с распределением latency (p50 vs p99).

**Лекция 4.3. Edge AI: Jetson Orin, Hailo-8, TFLite, CoreML, RKNN, OTA**
Перед лекцией подготовить:
сравнительную таблицу устройств по TOPS/Вт, экосистеме и формату модели;
при наличии Jetson/Raspberry Pi+Hailo — демонстрацию запуска квантованной модели.
Демонстрация должна включать:
разбор процесса конвертации модели в TFLite/RKNN с указанием на необходимость калибровочного датасета;
обсуждение требований OTA-обновления на кейсе распределённого парка устройств.
При отсутствии физических Edge-устройств можно продемонстрировать:
эмуляцию через документацию/видео производителей (NVIDIA Jetson, Hailo).

**Лекция 4.4. MLOps для инференса: model registry, A/B-тест, canary, drift detection**
Перед лекцией подготовить:
развёрнутый локально MLflow Model Registry (или скринкаст) с примером стадий None→Staging→Production;
пример дашборда Evidently AI с демонстрацией data drift.
Демонстрация должна включать:
пошаговый разбор Canary Deployment на условном кейсе (5%→20%→50%→100% трафика);
сравнение целей Canary Deployment и A/B-тестирования на конкретных примерах бизнес-метрик.
