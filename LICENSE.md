## Лицензия

Материалы репозитория распространяются на условиях лицензии **Creative Commons Attribution-NonCommercial-NoDerivatives 4.0 International (CC BY-NC-ND 4.0)**.

### Условия лицензии

- **Attribution (BY)** — необходимо указать авторов и источник.
- **NonCommercial (NC)** — материалы можно использовать только в некоммерческих целях.
- **NoDerivatives (ND)** — при перепубликации материалы следует оставлять без изменений.

При использовании материалов необходимо указывать ссылку на исходный репозиторий.

### Текст лицензии

Полный текст лицензии доступен по адресу: https://creativecommons.org/licenses/by-nc-nd/4.0/

### Применимость

Данная лицензия распространяется на все учебно-методические материалы, контрольно-измерительные материалы, лабораторные работы, проектные задания и документацию, содержащиеся в данном репозитории.

Если репозиторий содержит программный код, для него может быть выбрана отдельная лицензия (например, MIT или Apache License 2.0). В этом случае используется два файла:

- `LICENSE.md` — лицензия Creative Commons для учебных и методических материалов;
- `LICENSE-CODE.md` — лицензия для программного кода.
